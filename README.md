# Compilador joncailu

Vamos fazer um compilador de uma linguagem que possa ser utilizada para controlar uma turtle em uma grid quadriculada discreta.

Como decisões de projeto, nos propusemos em fazer na linguagem C, de forma que possa ser compilada para código Assembly e 
executada por um Arduino UNO, com microcontrolador ATmega328P.
